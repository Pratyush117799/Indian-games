Ashtapada · Step 1 — Design Blueprint

The Game That Gave Birth to Chess

8×8 spiral race · Castle sanctuaries · Cowrie dice · c.500 BCE · Pan-India

What makes Ashtapada unique vs Pagade

⊕ Spiral board

Path covers all 64 squares in a clockwise-inward spiral — no dead squares. Every cell matters. The board IS the path.

◈ Castle sanctuaries

12 special squares (corners + edge midpoints + centre) where pieces are completely safe. Strategic refuge is the core tension.

◎ The chess origin

This 8×8 board was inherited by Chaturanga (chess ancestor). Players feel they're touching the root of chess itself.

Board mechanics

⊙ The spiral path — 64 squares

  • Outer ring: 28 squares clockwise (top → right → bottom → left)
  • Ring 2: 20 squares (same clockwise direction, one layer in)
  • Ring 3: 12 squares spiralling inward
  • Ring 4: 4 centre squares — the final HOME destination
  • Total journey: 64 steps from entry to centre
  • Path visualised with subtle numbered overlay — player always knows where they are

◈ Castle squares (12 total)

  • 4 corners: the starting "home" castles for each player
  • 4 edge midpoints top/bottom: mid-journey sanctuaries
  • 4 edge midpoints left/right: tactical safe zones
  • Centre 4 squares: the ultimate destination / home
  • Visual: golden cross-mark on castle cells, glows when occupied
  • No capture possible on a castle — opponent piece bounces away visually

◉ Cowrie shell dice (4 shells)

0 mouth-up
Skip turn
1 mouth-up
Move 1
2 mouth-up
Move 2
3 mouth-up
Move 3
4 mouth-up (rare — 6.25%)
Move 8 squares — special throw

Probability distribution: 25% chance of 1 or 3, 37.5% chance of 2, 6.25% for skip or the special 8. Tension built into the math.

◎ Capturing & blocking

  • Land on opponent's piece (non-castle): they're sent back to start
  • Opponent on a castle: safe — your piece just passes over
  • Own two pieces on same square: form a blockade — opponent cannot pass
  • Blockade visual: two stacked pieces with a shield icon
  • Capture animation: attacker glows, captured piece spirals back
  • Centre squares: no capture — all pieces coexist peacefully in home
UI / UX design principles

◫ Board visual language

  • Monochrome base (historically authentic — no chess-style alternating colour)
  • Subtle spiral path trace visible at all times
  • Castle cells: gold diamond marker
  • Selected piece: white ring + valid moves pulse green
  • Path numbers fade in on hover for new players

⊕ Zero-instruction onboarding

  • First game: ghost piece auto-traces the full spiral before start
  • Castle squares introduced via first interaction — player lands, safe shield pops
  • Dice values shown as large icons, not text
  • Valid pieces pulse — tap any to move
  • "Chess ancestor" lore card appears on first win

◈ Cultural identity

  • Board texture: faint Vedic geometric pattern overlay
  • Castle marker: based on Indus Valley cross-hatch motif
  • Colour palette matches Pagade hub (indigo, saffron, sandstone)
  • Pieces: abstract pawns, not chess pieces (distinct identity)
  • Win screen: "You've traced the path of chess"
Animation library

◎ Cowrie roll

4 shells scatter, flip, settle one by one. Each mouth-up shell glows. Result shown as large number.

↻ Spiral move

Piece slides step-by-step along path (200ms/cell). Castle cells flash gold as piece passes through.

✕ Capture

Captured piece spins and retraces path back to start corner — reverse spiral animation.

★ Castle safety

Attempted capture on castle: attacker bounces back 1 square with a ripple effect. Shield icon pulses.

◈ Blockade

Two same-colour pieces merge visually into a double-pawn with a lock icon. Enemy piece bounces at the blockade.

◉ Home entry

Piece reaching centre 4 squares: lotus bloom + gold spin on that cell. Piece locks in with a satisfying click sound.

✦ Win celebration

All 4 home pieces glow simultaneously. "You've traced the path of chess" banner rises from board centre.

⊙ Skip turn

Roll 0: shells all face-down, board briefly dims, "Pass" badge fades across screen. No text needed.

Game modes & exclusive features

◈ Game modes

  • vs AI — 3 levels: Beginner / Prince / Maharaja
  • 2-player local — pass-and-play on same device
  • Online multiplayer — real-time via WebSocket
  • Solo sprint — race all 4 pieces home, compare times
  • Historic mode — Vedic board skin + parchment UI

◉ Exclusive features

  • "Chess ancestry tree" — visual showing Ashtapada → Chaturanga → Chess
  • Castle strategy guide unlocked after 5 games
  • Probability overlay: shows real-time % chance of rolling each value
  • Replay mode: watch any completed game step-by-step
  • Daily spiral challenge: specific board state, fewest moves to win
