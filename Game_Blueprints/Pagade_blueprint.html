Step 1 — Design Blueprint

Pagade Online — Game Design System

Mechanics · UI/UX · Animations · Engagement strategy
for children, casual players and ancient game lovers

Core design philosophy

✦ Minimal text

Icons, colour and animation replace explanatory text. Rules taught through play, not reading.

◎ Visual first

Every state change — move, capture, safe, home — is communicated purely through visual feedback.

⌬ Always responsive

One layout adapts from a 320px phone screen to a 1440px desktop — no pinching or zooming needed.

Board & game mechanics

⊕ Board geometry

  • Cross-shaped SVG board — rendered as pure vector, crisp at all screen sizes
  • 3 columns × 8 rows per arm, all labelled with subtle grid numbers
  • Centre Home square — visually distinct, animated glow ring
  • Each player arm in their signature colour (Red, Green, Yellow, Blue)
  • Safe squares marked with a lotus icon — no text needed
  • Belly zones shown with a subtle inner glow — "private zone" communicated by feel

◈ Dice mechanics

  • Animated cowrie shell dice — tap/click to roll, 3D flip animation
  • Result shown as large icon number + highlighted valid pawn moves
  • Doublet detection auto-highlights two split-move options
  • Invalid moves gently fade — no error messages, just visual cues
  • Optional: stick dice skin available in settings

  • Tap a pawn to select — it rises with a subtle lift shadow

UI / UX design

⊡ Screen layout

  • Centre: The board — full width on mobile, square on desktop
  • Top bar: Player avatars + score dots only — no score numbers for kids
  • Bottom tray: Dice area + a single action button (context-aware)
  • Corners: Mini player colour indicators — always visible
  • No sidebar, no panel, no menu during gameplay

◫ Player identity

  • Each player = one colour + one animal avatar (Lion, Elephant, Peacock, Tiger)
  • Avatar appears on each pawn — no text name needed
  • Active player's corner glows and pulses — instant clarity
  • Colour-blind mode: shape icons supplement colour cues
  • Children mode: extra-large pawns, slower animations

⬡ Onboarding — learn by doing

A ghost pawn travels the full route in 8 seconds — no words
First roll — guided highlight

First capture — brief colour flash
Screen celebrates the capture — player understands instantly
First home entry — grand celebration
Confetti rain + lotus bloom animation

⊕ Accessibility & comfort

  • Large tap targets — minimum 48×48px on mobile
  • Auto-zoom board to active pawn on small screens
  • One-handed play friendly — dice tap anywhere on bottom half
  • Undo last move (within 5 sec) — prevents accidental misclicks
  • Pause / resume game state saved locally
  • Font size scales with system preference
Visual theme & art direction

◈ Colour palette

Saffron #EF9F27 Forest #1D9E75 Indigo #7F77DD Sindoor #D85A30 Sandstone Neem #639922

Drawn from Karnataka's textile and temple art — Kasuti embroidery, Bidriware, Mysore silk. Every colour references a real cultural source.

⌘ Art style

  • Board texture: stylised Kasuti embroidery pattern as subtle SVG overlay
  • Pawns: silhouette shapes inspired by Mysore Dasara procession figures
  • Safe squares: Lotus (🪷) — universally understood symbol of safety
  • Home centre: Yantra geometry pattern, glows gold when a pawn enters
  • Background: warm sandstone — feels like a palace floor

Engagement & revisit mechanics

◈ Daily draw hook

  • "Daily Cowrie" — free daily dice roll gift on homepage
  • Streak counter shown as small flame — no text, just fire icon + number
  • 7-day streak unlocks an exclusive board skin (Hampi stone)
  • Monthly tournament calendar visible on landing page

◫ Community features

  • Quick emoji reactions during live game — no chat needed
  • Share board state as image — one tap to Instagram/WhatsApp
  • Public replay viewer — watch recorded games
  • Regional leaderboards: Karnataka · Goa · Maharashtra · Tamil Nadu

⊕ Progression system

  • Pawn skins unlocked by wins (Kasuti embroidery, Bidriware, Mysore silk)
  • Board themes: Temple Stone · Royal Silk · Night Festival
  • No pay-to-win — cosmetic only
  • Achievement badges drawn from Karnataka craft motifs

⌬ Game modes

  • Quick (2P): 2 pawns each — 10 min — for newcomers
  • Classic (4P): Full 4 pawns — authentic experience
  • Solo vs AI: 3 difficulty levels — Beginner / Prince / Maharaja
  • Pass & Play: same device, for families
  • Tournament: Bracket-based, seasonal

Technical approach

◈ Board rendering

Pure SVG board — vector, scalable, no canvas needed. CSS animations for all pawn movement.

⊕ Multiplayer

WebSocket real-time sync. Game state stored server-side — reconnect and resume anywhere.

◎ Offline / PWA

Installable as a PWA. Solo vs AI mode works offline. Syncs game state on reconnect.
