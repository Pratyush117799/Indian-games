## 🚀 BATCH GENERATION TIP

Create a spreadsheet with:
- Asset name
- Prompt
- Dimensions
- Priority (High/Medium/Low)
- Status (Not started/In progress/Done)

Generate in this order:
1. Protagonist sprites (all ages) - HIGHEST PRIORITY
2. Key NPCs (family, friends)
3. Home tilesets
4. School/college/office tilesets
5. UI elements
6. Props and objects
7. Cutscene illustrations
8. Special effects and emotes
