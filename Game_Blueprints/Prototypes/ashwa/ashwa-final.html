Integration into ui.js
Size on board
viewBox is 60×100. At 54px square: use width="50" height="83" — the piece fills the square width and extends slightly above square height (correct chess piece behaviour, taller than the square). At 40px: width="37" height="61". Position with position:absolute; bottom:0; left:50%; transform:translateX(-50%) inside the square so the base sits on the floor of the square.
Colour swap
Three colour values per army: pc (main), pc2 (highlight/ornament), pc3 (dark shadow). These are hardcoded inline in each SVG per army. To generate dynamically, pass the three hex values into the SVG template string in renderBoardGrid(). No CSS variables needed — direct attribute values work reliably across all browsers.
No clipPath required
Unlike the medallion prototype, this piece uses no clipPath elements. All shapes are contained within the viewBox naturally. This means you can safely reuse the same SVG string for every piece of the same type and army with no ID collision issues — safe for 16+ Ashwas on the board simultaneously.
